# Experiment reports

Outputs are generated locally into ignored outputs/ directories. Do not commit
real text, record mappings, model vocabularies, or participant-level summaries.

A complete report should state the question, eligible dataset version and hash,
annotation process, split strategy, package versions, seed, chosen hyperparameters,
validation decisions, metric definitions and uncertainty method. Include source-type
slices, failed examples, calibration, abstention coverage and external-validity limits.

No benchmark numbers are committed before execution. Synthetic outputs describe
software behavior only; they must not be presented as results from social-media users.
